OGP テスト用ページ

SNS のリンクプレビュー（OGP カード）の挙動を実機で確認するためのページ群です。 meta タグの組み合わせだけが異なるページを URL 単位で分けています。 SNS のクローラは URL 単位でキャッシュするため、同じ URL の meta を書き換えて使い回すと結果が汚れます。

ページ一覧

ページ og:title og:image og:description HTML title favicon
a.html OG-TITLE-A 赤 あり あり あり
b.html OG-TITLE-B 青 あり あり あり
c.html OG-TITLE-C 緑 あり あり あり
no-image.html あり なし あり あり なし
no-ogtitle.html なし 紫 あり あり あり
title-only.html なし なし なし あり なし
empty.html なし なし なし なし なし
notfound.html OG-TITLE-404 橙 あり あり あり

最後の行は実体のないパスです。 GitHub Pages がリポジトリ直下の 404.html を HTTP 404 として返すため、 「ステータスは 404 だが og タグは完備している」ページになります。 クローラが 404 のレスポンスボディから OGP を読むかどうかを切り分けるために使います。

投稿本文（コピー用）

SNS の投稿欄に貼り付けて、実際に表示されるカードを確認します。 カードの判定に画像・動画の添付が影響する SNS があるため、テキストのみで投稿してください。

A. カード対象 URL の選択

A-1: カード化できる URL が 2 つ（先頭か末尾か）

A-1 https://yuki383.github.io/ogp-tests/a.html https://yuki383.github.io/ogp-tests/b.html

A-2: 先頭がカード化できない（フォールバックするか）

A-2 https://yuki383.github.io/ogp-tests/empty.html https://yuki383.github.io/ogp-tests/a.html

A-3: URL が 3 つ（A-1 が先頭だった場合のみ）

A-3 https://yuki383.github.io/ogp-tests/a.html https://yuki383.github.io/ogp-tests/b.html https://yuki383.github.io/ogp-tests/c.html
